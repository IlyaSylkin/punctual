# ADR-003. Факт прибытия берётся из фида; геозона не строится

**Статус:** принято, 19.09.2026

## Контекст

Момент прибытия не публикуется напрямую ни одним стандартом. У HSL пройденные
остановки помечаются `uncertainty = 0` — это документировано:
*«uncertainty is set to 0 for stops which the vehicle has passed»*.

Значение правится: 4.8% фактов получают ровно одну правку, 99.6% вперёд,
медиана +10 с, обычно в пределах минуты после публикации.

## Решение

Факт прибытия = значение с `uncertainty = 0`, **не менявшееся 2 минуты**.

`current_status = STOPPED_AT` из фида позиций сохраняется рядом как независимая
проверка. Собственная геозона по координатам не строится.

## Альтернативы

**Своя геозона по координатам** — отвергнуто для HSL: дороже, вносит
собственную погрешность (подбор радиуса, ошибки GPS, пропуски между опросами),
а независимую проверку `STOPPED_AT` даёт бесплатно. Понадобится в фазе 3 для
городов без факта в фиде.

**Первое опубликованное значение факта** — отвергнуто: вносит в метрику
собственный шум порядка 10 секунд.

## Проверка

Расхождение между фактом из фида и `STOPPED_AT` должно оставаться в пределах
10 секунд. Измерено на 71 422 парах: медиана 4 с, p90 9 с. Источники независимы
(бортовая телеметрия HFP против операционной системы PubTrans). Рост расхождения
— основание пересмотреть решение.

## Следствия

**PostGIS уходит из фазы 1**: он был нужен только для геозоны.

Разрешающая способность метрики ограничена снизу примерно 10 секундами.
Превосходство меньше этого порога проект не заявляет.

Остаётся непроверяемое снаружи допущение: прогноз и факт HSL приходят из одной
закрытой системы PubTrans, и нельзя исключить, что выведены общей логикой.
