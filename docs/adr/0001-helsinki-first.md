# ADR-001. Хельсинки первым городом

**Статус:** принято, 19.09.2026

## Контекст

Метрика требует фактического времени прибытия. Замер 215 фидов из каталога
MobilityData показал: из 109 живых фидов признак «факт прибытия в самом фиде»
есть **у одного** — у HSL. Второй кандидат отпал по объёму (19 рейсов).

## Решение

Первый и единственный город фазы 1 — Хельсинки (HSL). Бостон переносится в
фазу 3 как контрольная группа.

## Альтернативы

**Бостон первым** — отвергнуто: факта прибытия в фиде нет, его пришлось бы
строить геозоной до первой цифры метрики; ниша занята дважды (агентство
публикует точность само, плюс независимый проект `overdue`).

**Оба города сразу** — отвергнуто: удваивает работу до первого результата.

## Проверка

Если факт HSL окажется непригодным, переходим на геозону, но город не меняем:
остальные свойства (объём, стабильность фида, открытая документация) остаются
лучшими среди проверенных.

## Следствия

HSL беднее полями, чем MBTA: нет `trip_id`, нет `stop_sequence`. Это плюс —
проектируем под самый бедный источник, и Бостон ляжет на ту же модель без
переделки. Обратный порядок потребовал бы миграции схем на накопленных данных.
