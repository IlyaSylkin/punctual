## Решения, помеченные к проверке

Три технологии приняты с явным условием, что их польза должна подтвердиться
на практике. Если к концу фазы 4 условие не выполнено, в соответствующем ADR
фиксируется, что технология не оправдалась.

| ADR | Что должно состояться |
|---|---|
| 007 ClickHouse | Postgres должен переломиться на кривой бенчмарка |
| 008 Kafka | нагрузочный тест на Entur **и** отказ потребителя без потерь |
| 011 Airflow | backfill должен реально понадобиться |
